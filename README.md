# WILDGUARD Frontend

Initial frontend-only prototype for the WILDGUARD AI wildlife early-warning system.

## Stack
HTML5 + CSS3 + Vanilla JavaScript

## Run
From this folder:

```bash
python3 -m http.server 5500
```

Open `http://localhost:5500`.

## Included
- Premium editorial homepage
- Elephant as primary target
- Sloth bear as secondary target
- Responsive navigation
- Detection / location / alert storytelling
- Live monitor preview
- Hardware ecosystem
- Technology architecture
- Scroll reveal interactions

All detection values shown are prototype presentation data and are not connected to real hardware yet.
